# 부산 여행 설정

## 일정 범위

- 기간: 8월 13일 목요일–8월 15일 토요일
- 숙소 기준: 대연역
- 상태: 날짜·시간 수정 가능
- 실행 페이지: `index.html`

## 지도 구성

- 부산 전역을 포함하는 고해상도 공통 정적 지도 1장
- 지도 제작 배율: CARTO `voyager_nolabels` 줌 15, 2배 타일
- 실행 중 외부 지도 요청 없음
- 공통 색상: 상위 `map_settings.md` 기준
- 세 날짜가 같은 지도 원본 사용
- 날짜별 위치·배율과 드래그·확대·축소 상태 독립 저장
- 확대·축소 버튼과 휠 간격: 기존 변화량을 두 단계로 분할
- 지도 화면 비율 자동 보정 및 원본 바깥 이동 제한
- 날짜별 화면 확정
- 오른쪽 위 `전체보기` 선택 시 해당 날짜 기본 화면으로 복귀

- 버스 요금 미표시
- 택시 예상 요금만 표시
- 지도 경로: 이동 구간 전체를 도보 주황 점선, 버스 파랑 실선, 택시 초록 실선으로 표시
- 지도 위 교통수단·소요시간 문구 미표시
- 시간표에는 장소명과 시작 시간만 표시. 주소와 종료 시간 미표시
- 장소별 어울리는 아이콘 표시
- 기본 지도에는 장소만 표시. 도착 장소 행 선택 시 해당 이동 경로 하나만 표시
- 선택한 행 오른쪽에는 `버스로 12분`, `택시로 17분`, `도보로 3분` 형식만 표시
- 첫 장소는 출발점이므로 경로 선택 기능 미적용
- 장소 핀: 테두리 없는 검은색 원형, 장소명은 기본적으로 핀 위 가운데 배치
- 가까운 장소는 겹침 방지를 위해 이름을 핀 오른쪽·아래쪽에 예외 배치
- 핀 위치 보정 연결선 미표시. 핀과 장소명 말풍선 사이 여백 12 단위로 통일
- 날짜별 지도 기본 배율과 관계없이 핀·번호·장소명 크기는 Day 1 화면 크기로 통일
  - 네이버 지도 사용자 제공 화면 기준

## 지도 다시 만들기

```powershell
python .\tools\build_busan_maps.py
```

지도 범위 변경 시 스크립트의 `MAPS` 값 수정. 생성 후 `app.js`의 이미지 크기와 `tileOrigin`을 출력값에 맞춰 변경.
